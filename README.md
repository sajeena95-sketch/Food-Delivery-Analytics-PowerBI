# 🍔 Food Delivery Analytics Dashboard using Power BI

## 📌 Project Overview

This project focuses on analyzing food delivery business data using **Power BI**. The dashboard transforms raw data into interactive visualizations, helping businesses understand order trends, revenue, delivery performance, customer ratings, and food preferences.

---

## 🎯 Problem Statement

Food delivery businesses generate large volumes of data every day. Manual analysis is time-consuming and makes it difficult to identify important business trends. This project aims to build an interactive Power BI dashboard that provides meaningful insights for better decision-making.

---

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX (Data Analysis Expressions)
- Microsoft Excel

## ✨ Dashboard Features

- 📈 KPI Cards (Total Orders, Revenue, Average Delivery Time & Rating)
- 🏙️ Orders by City
- 🍽️ Revenue by Restaurant
- 🍕 Food Category Analysis
- 📅 Monthly Revenue Trend
- 🎛️ Interactive Dashboard
- 🔍 Dynamic Filtering using Slicers

---

## 📈 Key Insights

- Chennai recorded the highest number of food orders.
- Royal Biryani generated the highest revenue.
- Average delivery time is approximately **53 minutes**.
- Average customer rating is around **3 out of 5**.
- Snacks and South Indian food categories were among the most popular.
